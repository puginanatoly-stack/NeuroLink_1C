# OData — интеграция 1С через OData (MCP)

Работа с данными 1С:Предприятие на естественном языке через стандартный интерфейс
**OData** и **MCP-сервер** `1c-odata-mcp`. Позволяет читать справочники, документы,
регистры и делать аналитику из любого MCP-клиента (opencode, Claude, Cursor и др.),
не ставя ничего внутрь 1С.

## Структура каталога

| Путь | Назначение |
|---|---|
| `mcp-server/` | Исходники MCP-сервера `1c-odata-mcp` (Node.js 20+, TypeScript). Ставится через `npm install && npm run build`, запускается `dist/index.js` или `npx -y 1c-odata-mcp` |
| `external-processor/` | Внешняя обработка «Настройка состава OData» — заполняет «Состав OData» в 1С одной кнопкой (исходники `src/` + готовый `build/НастройкаСоставаOData.epf`) |
| `scripts/` | JS-скрипты прямых запросов к OData (разведка схемы, выгрузка данных) |
| `.env.example` | Шаблон конфигурации подключения (копировать в `mcp-server/.env`) |

## Быстрый старт

### 1. Публикация OData в 1С

- База должна быть опубликована через веб-сервер (Apache/IIS) с включённым OData.
- Адрес: `http://<сервер>/<имя_публикации>/odata/standard.odata/` (завершающий слэш обязателен).
- Подробно — `mcp-server/docs/CONNECTING.md` и `mcp-server/docs/ODATA-SETUP.md`.

### 2. Заполнить «Состав OData»

Иначе объекты недоступны (`EntitySet: 0`). Два способа:

- **Программно** (рекомендуется): открыть `external-processor/build/НастройкаСоставаOData.epf`
  в 1С (**Файл → Открыть**) → кнопка «Заполнить состав OData». Обработка включает все
  справочники, документы, перечисления, регистры и планы видов расчёта через
  `УстановитьСоставСтандартногоИнтерфейсаOData(Массив)`.
- **Вручную**: Все функции → Обработки → «Настройка стандартного интерфейса OData» →
  вкладка «Состав» → отметить объекты → Записать.

### 3. Настроить подключение

```bash
cd mcp-server
cp .env.example .env   # заполнить ODATA_BASE_URL / ODATA_USERNAME / ODATA_PASSWORD
npm install
npm run build
```

### 4. Проверить

```bash
node --env-file=.env dist/scripts/probe-metadata.js   # карта объектов + сверка имён
node --env-file=.env dist/scripts/probe-mcp.js        # end-to-end по протоколу MCP
```

### 5. Подключить к MCP-клиенту

```json
{
  "mcpServers": {
    "1c-odata": {
      "type": "local",
      "command": ["node", "--env-file=<abs>/mcp-server/.env", "<abs>/mcp-server/dist/index.js"],
      "enabled": true
    }
  }
}
```

Пароль хранится в `.env` (не в конфиге клиента).

## Ограничения

- Сервер заточен под **Бухгалтерию 3.0**: имена объектов и аналитика (дебиторка, остатки
  по плану счетов «Хозрасчётный») привязаны к БП. На **ЗУП/HRM** чтение справочников,
  документов и регистров работает, а бухгалтерская аналитика — нет.
- Работает только через **OData** (не COM, не прямой SQL).
- Запись по умолчанию выключена (`READ_ONLY=true`); включается двумя флагами + dry-run.

## Скрипты (`scripts/`)

Примеры прямых HTTP-запросов к OData (для разведки и выгрузки данных без MCP):

- `odata_fizlitsa_list.js` — список физических лиц
- `odata_fizlitsa_age30.js` — физ.лица старше 30 лет (фильтр по дате рождения)
- `odata_salary_result.js` — начисленная зарплата сотрудника по месяцам
- `odata_bolnich_age.js` — больничные листы + группировка по возрасту
- `odata_docs_count.js` — количество записей по списку документов

Каждый скрипт самодостаточен: `node scripts/<имя>.js`.
